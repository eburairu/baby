## 2024-05-18 - IDOR Vulnerability in Comments API
**脆弱性:** `delete_comment` エンドポイントにおいて、ユーザーが管理者権限（ADMIN）を持っているかを確認する際、対象の赤ちゃん（またはコメント）が属する `family_id` を考慮せずに、`FamilyUser.user_id == current_user.id` のみで `FamilyUser` を取得していました。
**学び:** ユーザーが複数のファミリーに所属できるシステム設計において、権限チェックを行う際に `family_id` の絞り込みが欠落していると、あるファミリーでの管理者権限を使って、全く別のファミリーのリソースを操作できてしまう「認可バイパス（IDOR）」が発生します。
**予防:** 複数コンテキスト（マルチテナント/マルチファミリー）に属するユーザーの権限を検証する場合は、常に「対象リソースが属するコンテキストID（今回であれば `family_id`）」をクエリのフィルタ条件に含めること。
