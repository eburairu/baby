# Scout Journal

2025-02-26 - [Fat Componentと重複UIの発見]
学び:
- `FeedingForm` (22KB) や `DashboardLayout` (18KB) など、一部の主要コンポーネントが肥大化している。特にフォームコンポーネント内にタイマーロジックや条件分岐による複雑なレンダリングが混在しており、可読性が低下している。
- `FeedingForm` と `DiaperForm` で、非常に似通った「アイコン付き選択ボタン」や「チップ型選択UI」が個別に実装されている。これらを共通化することで、コードの重複を減らし、UIの一貫性を向上させることができる。
- `GrowthChart` では、グラフ描画の設定とデータ処理ロジックが混在しており、将来的な拡張（例：別の種類のグラフ追加）が難しくなっている。

アクション:
- フォーム系コンポーネントのリファクタリングを優先的に行い、ロジック（カスタムフック）とUI（サブコンポーネント）を分離する。
- 共通UIパターン（SelectionGroup, ChipGroupなど）を抽出し、`components/ui` 配下に再利用可能な形で実装することを提案する。
