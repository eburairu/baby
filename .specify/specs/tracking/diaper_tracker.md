# おむつ交換記録機能 仕様書 (Diaper Tracker Specification)

## 概要

赤ちゃんの排泄（おむつ交換）を記録・管理するためのフロントエンド機能。
排泄の種類（おしっこ/うんち/両方）と時間を素早く記録し、赤ちゃんの健康状態把握に役立てる。

## ユーザーストーリー

- 親として、おむつ交換のたびに素早く記録をつけたい（特に夜間やお出かけ時）
- 「いつ」「どんな」排泄があったかを振り返りたい
- **最近の記録リストで、うんちかおしっこかを一目で区別したい**
- 便秘気味かどうかや、おしっこの回数（脱水症状の兆候など）を確認したい

## 機能要件

### F1: おむつ交換記録入力

- **種類選択**: 以下の3タイプから選択する
    - 💧 おしっこ (WET)
    - 💩 うんち (DIRTY)
    - 💧💩 両方 (BOTH)
- **時刻設定**:
    - デフォルトは「現在時刻」
    - 過去の記録もできるよう、時刻編集が可能
- **メモ入力**: 色や量、状態などを自由記述（任意）
- **保存**: 記録ボタン押下で API に POST する

### F2: おむつ記録一覧 (タイムライン)

- 直近の記録を時系列（新しい順）で表示
- **視覚的な区別 (重要)**:
    - 種類によってアイコンや背景色/文字色を変えるなどして、直感的に判別可能にする。
    - 例: おしっこは青系/水色、うんちは茶色/オレンジ系、両方は紫/混合色など。
- 各記録に以下を表示:
    - 時刻
    - 種類アイコン（💧 / 💩 / 💧💩）とラベル
    - **記録者名**: `recorded_by_display_name` を表示（例：「ママ」「パパ」）。`null`（削除済みユーザー）の場合は表示省略または「不明」と表示。
    - メモ（あれば）
- 個別の記録を削除できる

### F3: 統計サマリー (Daily)

- **今日の回数**:
    - おしっこ回数（WET + BOTH）
    - うんち回数（DIRTY + BOTH）
    - 合計回数
- **前回からの経過時間**: おしっこ/うんちそれぞれの最後の記録からの経過時間を表示

## バックエンド API (既存)

以下の API は既に実装済み:

- `GET /api/diapers/?baby_id={id}` - 記録一覧取得
- `POST /api/diapers/` - 記録作成
- `DELETE /api/diapers/{id}` - 記録削除

### リクエスト/レスポンス スキーマ

```typescript
enum DiaperType {
  WET = "WET",
  DIRTY = "DIRTY",
  BOTH = "BOTH"
}

// POST リクエスト
interface DiaperCreate {
  baby_id: number
  change_time: string // ISO 8601
  diaper_type: DiaperType
  notes?: string
}

// レスポンス
interface DiaperResponse extends DiaperCreate {
  id: number
  user_id: number
  recorded_by_display_name: string | null  // 記録者の表示名（ユーザーが削除された場合はnull）
}
```

## 技術設計

### データ取得 (SWR)

- `useDiapers(babyId)` カスタムフックを作成 (既存のものを拡張/利用)

### コンポーネント構成

- `DiaperPage` - ページコンポーネント (`app/(dashboard)/diaper/page.tsx`)
- `DiaperForm` - 入力フォーム（種類選択、時刻、メモ）
- `DiaperStats` - 今日の回数・前回からの経過時間表示
- `DiaperHistory` - 履歴リスト。**ここでの種別ごとのスタイル分けが重要**。
