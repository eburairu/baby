# 睡眠記録機能 仕様書 (Sleep Tracker Specification)

## 概要

赤ちゃんの睡眠（お昼寝、夜の睡眠）を記録・管理するためのフロントエンド機能。
睡眠の開始・終了時刻を記録し、睡眠時間やリズムを把握するのに役立てる。

## ユーザーストーリー

- 親として、赤ちゃんが寝た時間（開始）と起きた時間（終了）を記録したい（リアルタイムまたは事後）。
- 現在寝ているかどうかの状態をアプリ上で把握したい。
- 1日の合計睡眠時間や、日中・夜間の睡眠バランスを確認したい。
- 過去の睡眠記録を修正・削除したい。

## 機能要件

### F1: 睡眠記録入力 (タイマー/手動)

- **モード**:
    - **タイマー (リアルタイム)**:
        - 「おやすみ (Start)」ボタンで睡眠開始を記録。
        - 「おはよう (Stop/Wake Up)」ボタンで睡眠終了を記録。
        - 現在の状態（睡眠中/起床中）を表示。
    - **手動 (Manual)**:
        - 開始日時と終了日時を指定して過去の記録を追加。
- **入力項目**:
    - 開始日時 (Start Time): 必須。
    - 終了日時 (End Time): 任意（進行中の場合は未設定）。
    - メモ: 自由記述（例: 「抱っこで寝落ち」「夜泣きあり」など）。
- **保存**: API に POST/PATCH して保存する。
    - **処理中フィードバック（新規・HIGH）**: 保存ボタン（および開始/停止ボタン）が押された後、API レスポンスが返るまでの間、ボタンを無効化（Disabled）し、テキスト置換（「保存」→「保存中...」）およびスピナーを表示して処理中であることを示す。二重送信を完全に防止する。
    - **家族への通知**: 記録作成成功時、対象の赤ちゃんの家族メンバー全員に通知（Webプッシュ/アプリ内通知）が送信される。
        - タイトル: "睡眠の記録"
        - 本文: "{記録者名}さんが{赤ちゃん名}の睡眠を記録しました。"

### F2: 睡眠記録一覧 (タイムライン)

- 直近の記録を時系列（新しい順）で表示。
- 各記録の表示内容:
    - 開始時刻 ～ 終了時刻
    - 睡眠時間（例: 1時間30分、進行中の場合は「睡眠中 (1h 15m経過)」など）
    - **記録者名**: `recorded_by_display_name` を表示（例：「ママ」「パパ」）。`null`（削除済みユーザー）の場合は表示省略または「不明」と表示。
    - メモ（あれば）
- 記録の編集・削除機能。
    - 削除確認ダイアログを表示し、誤操作を防ぐ。
    - 削除処理中は確認ダイアログの「削除」「キャンセル」ボタンを無効化し、二重送信を防ぐ。

### F3: 統計サマリー (Daily)

- **今日の合計**:
    - 睡眠回数
    - 合計睡眠時間
- **視覚化 (Optional/Future)**:
    - 24時間のバーチャート表示（タイムライン）。

## バックエンド API / データモデル

新規 `Sleep` モデルおよび API を作成する。

### モデル (`Sleep`)

- `baby_id`: FK (Integer)
- `user_id`: FK (Integer) - 記録者（ログインユーザーのID）
- `start_time`: DateTime (UTC, 必須)
- `end_time`: DateTime (UTC, Nullable) - Nullの場合は「現在睡眠中」を表す
- `notes`: Text (Nullable)

### API

- `GET /api/sleeps/?baby_id={id}`: 指定した赤ちゃんの睡眠記録一覧を取得
- `POST /api/sleeps/`: 新しい睡眠記録を作成（開始）
    - **通知**: 記録作成成功時、対象の赤ちゃんの家族メンバー全員に通知（Push/In-App）が送信される。
- `PATCH /api/sleeps/{id}`: 既存の睡眠記録を更新（終了時間の記録、修正）
- `DELETE /api/sleeps/{id}`: 削除

### リクエストスキーマ (`SleepCreate` / `SleepUpdate`)

```typescript
// Create (Start)
interface SleepCreate {
  baby_id: number
  start_time: string // ISO 8601
  end_time?: string  // Optional (for manual entry)
  notes?: string
}

// Update (End / Edit)
interface SleepUpdate {
  start_time?: string
  end_time?: string  // Set this to stop the timer
  notes?: string
}
```

### レスポンススキーマ (`SleepResponse`)

```typescript
interface SleepResponse extends SleepCreate {
  id: number
  user_id: number
  recorded_by_display_name: string | null  // 記録者の表示名（ユーザーが削除された場合はnull）
  comment_count: number
}
```

## 技術設計

### コンポーネント構成案

- `SleepPage` (`app/(dashboard)/sleep/page.tsx`)
- `SleepTimer`: 現在のステータス表示とStart/Stopアクション
- `SleepForm`: 手動入力・編集用フォーム
- `SleepHistory`: 履歴リスト表示
- `SleepStats`: 今日のサマリー表示

### 状態管理

- **現在の睡眠状態**:
    - 最新の `Sleep` レコードを取得し、`end_time` が `null` であれば「睡眠中」と判定。
    - 睡眠中の場合、タイマー（経過時間）は `start_time` と現在時刻の差分でクライアントサイド計算・表示。
- データ取得は SWR (`useSWR`) を利用し、フォーカス時に再検証して最新状態を保つ。
