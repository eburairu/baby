# 予防接種スケジューラー 仕様書 (Vaccination Tracker Specification)

## 概要

赤ちゃんの予防接種スケジュールを管理し、推奨される接種時期を自動計算して親に提案する機能。
接種忘れを防止し、複数のワクチンのスケジュールを一括で把握できる。

## ユーザーストーリー

- 親として、いつどのワクチンを打つべきかを把握したい。
- 赤ちゃんの誕生日に合わせて、自動的に推奨スケジュールを提示してほしい。
- 接種した際に、ロット番号や接種場所、副反応などをメモしておきたい。
- 接種予定日が近づいたら通知を受け取りたい。

## 機能要件

### F1: 推奨スケジュール自動生成

- **ロジック**:
    - 赤ちゃんの `birthday` から、日本の標準的な定期・任意接種スケジュールを計算する。
    - 推奨時期（例：生後2ヶ月から、1回目から27日以上あけて等）に基づいて、デフォルトの予定日を設定。
- **対象ワクチン (初期リスト)**:
    - **ロタウイルス**: 1回目(生後6週-), 2回目, 3回目(ロタテックのみ)
    - **ヒブ (Hib)**: 1回目(生後2ヶ月-), 2回目, 3回目, 追加接種
    - **小児用肺炎球菌 (PCV15)**: 1回目(生後2ヶ月-), 2回目, 3回目, 追加接種
    - **B型肝炎**: 1回目(生後2ヶ月-), 2回目, 3回目
    - **5種混合 (DPT-IPV-Hib)**: 1回目(生後2ヶ月-), 2回目, 3回目, 追加接種
        - ※4種混合 + ヒブからの移行を考慮
    - **BCG**: 1回目(生後5ヶ月-1歳未満, 標準は5-8ヶ月)
    - **MR (麻疹・風疹)**: 第1期(1歳-2歳未満)
    - **水痘 (みずぼうそう)**: 1回目(1歳-), 2回目
    - **おたふくかぜ**: 任意接種(1歳-)
    - **日本脳炎**: 1期(3歳-)

### F2: 接種記録入力・ステータス管理

- **入力項目**:
    - **ワクチン名 / 回数**: リストから選択（または自動生成されたものを使用）。
    - **ステータス**: `予定 (Scheduled)`, `完了 (Completed)`, `延期 (Postponed)`。
    - **接種日**: 実際に行った日。
    - **ロット番号**: 記録用。
    - **医療機関名**: 記録用。
    - **副反応の有無**: チェックボックスとメモ。
- **保存**: API に POST/PUT して保存する。
    - 保存成功後、家族全員に通知（"予防接種記録: {赤ちゃん名}が{ワクチン名}を接種しました。"）。

### F3: スケジュール一覧 (Timeline View)

- 縦軸に時期（生後2ヶ月、3ヶ月...）、横軸にワクチンの種類を並べた一覧表示。
- 未完了の予定、接種済みの項目を一目で区別できるようにする。

### F4: リマインダー通知

- 接種予定日の1週間前、3日前、当日の朝にプッシュ通知を送信する。

## データモデル

### モデル (`VaccinationRecord`)

- `id`: Integer (PK)
- `baby_id`: Integer (FK -> babies.id)
- `user_id`: Integer (FK -> users.id) - 記録者
- `vaccine_name`: String (例: "Hib")
- `dose_number`: Integer (例: 1)
- `status`: Enum (`scheduled`, `completed`, `postponed`)
- `scheduled_date`: Date (推奨または手動設定された予定日)
- `completed_date`: Date (実際に接種した日)
- `lot_number`: String (Nullable)
- `hospital_name`: String (Nullable)
- `has_side_effect`: Boolean (Default: False)
- `notes`: String (Nullable)

## API

- `GET /api/vaccinations/?baby_id={id}`
    - 記録済みおよび生成された全スケジュールを取得。
- `POST /api/vaccinations/`
    - 手動での記録追加または一括生成（初回アクセス時など）。
- `PATCH /api/vaccinations/{id}`
    - ステータス更新（完了への変更など）。
- `DELETE /api/vaccinations/{id}`
    - 記録の削除。

## 技術設計

### スケジュール算出サービス (`VaccinationService`)

生年月日から以下の基準で日付を生成するロジックを実装。
- ロタウイルス1回目: 生後6週〜
- ヒブ/肺炎球菌1回目: 生後2ヶ月〜
- ... 等々、標準的なガイドラインに基づく。
