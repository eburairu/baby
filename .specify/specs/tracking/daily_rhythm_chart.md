# 生活リズムチャート仕様書 (Daily Rhythm Chart Specification)

## 概要

過去7日間の記録データを使って、「1日のどの時間帯に記録が集中しているか」を可視化するチャート機能。
生活リズムのパターン発見と、次回記録タイミングの予測に役立てる。

授乳・おむつ・睡眠のそれぞれのページに既存の「7日間の推移」グラフ（`FeedingChart` / `DiaperChart`）と**同一カード内でタブ切り替え**できる形で組み込む。

## ユーザーストーリー

- 親として、授乳が1日のどの時間帯に行われているかを一目で把握し、赤ちゃんの生活リズムを理解したい。
- おむつ替えの時間帯パターンを見て、夜間対応の準備や日中のスケジュール調整に活かしたい。
- 睡眠のリズムを把握して、次のお昼寝や夜の就寝がいつ頃になりそうかを予測したい。
- 7日間のデータを比較し、毎日ほぼ同じ時間帯に記録されているかどうかを確認したい（リズムの安定性）。

## 機能要件

### F1: チャートビューの切り替え

既存の「7日間の推移」グラフカードに、表示ビューを切り替えるトグル（ピルボタン）を追加する。

```
┌─────────────────────────────────────────────┐
│  [ 推移 │ リズム ]   ← トグルボタン          │
│                                             │
│  [グラフ本体（選択中のビューに応じて切り替え）] │
└─────────────────────────────────────────────┘
```

- **推移ビュー** (デフォルト): 既存の日別棒グラフ（`FeedingChart` / `DiaperChart` の現在の実装）
- **リズムビュー**: 新規追加するドット散布図

選択状態は `localStorage` に保存し、ページ再訪時に復元する。

### F2: リズムチャート (Shape Timeline Chart)

#### チャートタイプ

**シェイプ散布図 (Shape Plot)** を採用する。記録種別ごとに異なるシェイプを使って視覚的に区別しやすくする。

```
時刻  0:00          6:00         12:00        18:00        24:00
      ─────────────────────────────────────────────────────────
今日  │         ♥        ♥💧      ▼     ♥💧💧        ▼    │
昨日  │    💧        ♥       ▼💧💧         ♥♥    ▼      │
2日前 │         ♥    💧        ▼▼     💧♥        ▼     │
      ─────────────────────────────────────────────────────────
```

- **X軸**: 時刻（0:00 〜 24:00）。モバイルは3時間おき、デスクトップは6時間おきに目盛りを表示
- **Y軸**: 日付（今日 → 6日前、新しい順に上）
- **シェイプ**: 1記録 = 1シェイプ。同時刻に複数記録が重なる場合は Y 方向にわずかにずらして重なりを軽減（jitter）
- **ホバー/タップ**: シェイプにタッチすると、その記録の時刻と内容（種別、量など）をツールチップで表示

#### シェイプ定義

各記録種別にシェイプと色を割り当てる。

**授乳ページ**

| 種別 | シェイプ | カラー |
|------|----------|--------|
| 母乳 (BREAST) | ハート（♥） | Rose |
| ミルク (BOTTLE) | 雫（💧） | Amber |

**おむつページ**

| 種別 | シェイプ | カラー |
|------|----------|--------|
| おしっこ (WET) | 雫・上が尖った水滴形（💧） | Sky |
| うんち (DIRTY) | 上向き三角（▲） | Amber |
| 両方 (BOTH) | 雫 + 上向き三角（💧▲） | Purple（2つのシェイプを並べて表示） |

#### 技術実装メモ

- `recharts` の `ScatterChart` + カスタム `shape` prop で SVG シェイプを描画する
- ハート: SVG path (`M 0,-r C ...`) またはテキスト文字（`♥`）
- 雫: SVG path（上端が尖り下端が丸い水滴形 ＝ teardrop）
- 三角: SVG polygon（上向き正三角形）
- シェイプのサイズは半径 `r=5` 相当で統一し、視認性を確保する

### F3: 次回予測インジケーター

過去7日の記録間隔の中央値から「次回予測時刻」を算出し、チャート上に表示する。

- **算出方法**: 過去7日間の全記録を時系列で並べ、連続する記録間の間隔の中央値を算出する
- **表示**: X軸上の「最終記録時刻 + 中央値間隔」の位置に垂直の点線と「予測」ラベルを表示
- **表示条件**: 過去7日間に5件以上の記録がある場合のみ表示（データ不足時は非表示）
- **サマリーテキスト**: チャート上部に「平均間隔: 約X時間」と表示

## データ要件

### 使用 API

各ページで使用している既存のエンドポイントを再利用する。チャート専用のAPIは新設しない。

| ページ | エンドポイント |
|--------|---------------|
| 授乳 | `GET /api/feedings/?baby_id={id}` |
| おむつ | `GET /api/diapers/?baby_id={id}` |
| 睡眠 | `GET /api/sleeps/?baby_id={id}` |

フロントエンドで `timestamp >= 7日前の00:00:00` の条件でフィルタリングする。

### データ変換ロジック

```typescript
interface RhythmChartDataPoint {
  dayOffset: number;   // 0=今日, 1=昨日, ..., 6=6日前
  timeMinutes: number; // 0〜1439 (0:00〜23:59を分単位で表現)
  label: string;       // ツールチップに表示するテキスト
  color?: string;      // 記録タイプ別カラー（授乳ページのみ使用）
}
```

睡眠は開始時刻 (`start_time`) をプロットする（「いつ眠くなるか」のリズムを把握するため）。

## 技術設計

### ライブラリ

既存の `recharts` を使用する。新しいライブラリの追加は不要。
リズムチャートは `recharts` の `ScatterChart` で実装する。

### コンポーネント構成

既存の `FeedingChart.tsx` / `DiaperChart.tsx` にタブ切り替えロジックとリズムビューを追加する。
リズムチャートのロジックは共有ユーティリティ（`frontend/lib/rhythmUtils.ts`）として抽出し、各チャートコンポーネントから呼び出す。

```
frontend/lib/
  └── rhythmUtils.ts              # 共有ユーティリティ（新規作成）
      - buildRhythmData()         # 記録配列 → RhythmChartDataPoint[] に変換
      - calcMedianIntervalMin()   # 中央値間隔の算出

frontend/components/feeding/
  └── FeedingChart.tsx            # 既存。タブ + RhythmView を追加

frontend/components/diaper/
  └── DiaperChart.tsx             # 既存。タブ + RhythmView を追加

frontend/components/sleep/
  └── SleepChart.tsx              # 新規作成（睡眠ページ用）
```

### 状態管理

- タブの選択状態は各チャートコンポーネントの `useState` で管理する
- `localStorage` のキー:
  - 授乳: `feeding-chart-view`
  - おむつ: `diaper-chart-view`
  - 睡眠: `sleep-chart-view`
- 値: `"trend"` | `"rhythm"`

## 受け入れ条件 (AC)

1. グラフカード上部に「推移 / リズム」のトグルボタンが表示される
2. 「推移」タブでは既存の棒グラフが変わらず表示される
3. 「リズム」タブに切り替えると、過去7日間の記録がドット散布図（X=時刻・Y=日付）で表示される
4. ドットをタップ/ホバーすると記録の詳細（時刻、種別など）がツールチップで表示される
5. 授乳ページでは母乳（Rose・ハート）とミルク（Amber・雫）でシェイプと色が区別される
5a. おむつページではおしっこ（Sky・雫）とうんち（Amber・上向き三角）でシェイプと色が区別される
6. 過去7日間の記録が5件以上ある場合のみ、予測ライン（点線）と「平均間隔: 約X時間」が表示される
7. チャートはモバイル（375px幅）でも崩れずに表示される
8. タブの選択状態は `localStorage` に保存され、ページ再訪時に復元される
9. タブ切り替えでカードの高さが変化しない（200px 固定）
