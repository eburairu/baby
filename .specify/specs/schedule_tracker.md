# スケジュール記録 仕様書 (Schedule Tracker Specification)

## 概要

赤ちゃんの予定（予防接種、検診、お出かけなど）を記録し、家族で共有・管理できる機能。
完了状態の管理も可能。

## ユーザーストーリー

- 親として、赤ちゃんの今後の予定を登録しておきたい。
- 家族全員が同じスケジュールを確認できるようにしたい。
- 予定が完了したかどうかをチェックしたい。
- 予定のタイトルだけでなく、詳細な内容もメモしておきたい。

## 機能要件

### F1: スケジュール入力

- **入力項目**:
    - **赤ちゃんID**: 記録対象の赤ちゃん。
    - **タイトル**: 予定の名称（例: 予防接種）。必須。
    - **説明**: 予定の詳細（例: BCGワクチン、14:00から）。任意。
    - **予定日時**: 予定が実施される日時。必須。
    - **完了フラグ**: 予定が完了したかどうか。デフォルトは未完了。
- **保存**: API に POST して保存する。

### F2: スケジュール一覧

- 指定した赤ちゃんのスケジュールを時系列（予定日時順）で取得・表示。
- 未完了・完了の区別が可能。

### F3: スケジュール削除

- 登録したスケジュールを削除可能。

## データモデル

### モデル (`Schedule`)

- `id`: Integer (PK)
- `user_id`: Integer (FK -> users.id) - 作成者
- `baby_id`: Integer (FK -> babies.id) - 対象の赤ちゃん
- `title`: String (必須)
- `description`: String (任意)
- `scheduled_time`: DateTime (必須)
- `is_completed`: Boolean (デフォルト: False)
- `created_at`: DateTime (自動設定)

## API

- `GET /api/schedules/?baby_id={id}`
    - 指定した赤ちゃんのスケジュール一覧を取得。
- `POST /api/schedules/`
    - 新規スケジュールを作成。
- `DELETE /api/schedules/{id}`
    - 指定したスケジュールを削除。

## 権限管理

- `verify_baby_access` を通じて、対象の赤ちゃんへのアクセス権限があるユーザーのみが操作可能。
- 家族メンバーであれば閲覧・作成・削除が可能。
