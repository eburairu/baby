# 設定ナビゲーション仕様書 (Settings Navigation Specification)

## 概要

設定トップページ (`/settings`) のレイアウトと、各設定項目へのナビゲーション、およびログアウト機能について定義する。

## 1. 画面構成

設定画面は以下のセクションで構成される。

### 1.1 一般セクション

アプリ全体の動作や表示に関する設定。

- **表示モード**: ダークモード/ライトモード/システム設定の切り替えトグル (`ThemeToggle`) を配置。

### 1.2 アカウント・管理セクション

ユーザーや家族、データ管理に関する設定。

- **プロフィール設定**: 表示名の変更 (`/settings/profile`)。
- **家族設定**: 家族名・招待コード・メンバー管理 (`/settings/family`)。
- **赤ちゃん管理**: 赤ちゃんの情報の追加・編集・削除 (`/settings/babies`)。

### 1.3 ログアウト

- **ログアウトボタン**: アカウント・管理セクションの末尾、またはページ最下部に配置する。
- **スタイル**: `variant="ghost"` または `variant="outline"` の控えめなデザインを使用する。基本的にログアウトは行わないため、目立たせすぎないようにする。
- **確認**: 誤操作防止のため、クリック時に確認ダイアログ（AlertDialog）を表示する。

## 2. デザインガイドライン

- `ui_design_system.md` に従い、各項目は `Card` または `List` 形式で表示する。
- 各ナビゲーション項目には、内容を想起させるアイコン（Lucide React）と、右側に `ChevronRight` を配置する。

## 3. ログアウトの挙動

- ログアウト実行時は `api.post("/auth/logout")` を呼び出し、成功後に `/login` ページへ遷移する。
- クライアント側の状態（SWRキャッシュ等）をクリアする。
