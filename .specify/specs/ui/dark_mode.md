# ダークモード仕様書

## 概要

Baby App にダークモードを導入し、夜間の授乳や記録作業時の視覚的負担を軽減する。
システム設定への追従、および手動での切り替えをサポートする。

## 背景・目的

赤ちゃんのお世話（特に授乳やおむつ替え）は夜間に行われることが多く、ライトモードの強い光は親と赤ちゃんの双方にとって刺激が強い。
ダークモードを導入することで、暗い部屋でも快適にアプリを利用できるようにする。

## 1. デザイントークン（ダークモード用）

### 1.1 基本カラーのカラーマッピング

| 用途 | ライトモード (現状) | ダークモード (新規) |
|------|-------------------|-------------------|
| ページ背景 | `bg-slate-50` | `bg-zinc-950` |
| カード背景 | `bg-white` | `bg-zinc-900` |
| 主要テキスト | `text-gray-800` | `text-zinc-100` |
| 補助テキスト | `text-gray-500` | `text-zinc-400` |
| 非活性テキスト | `text-muted-foreground` | `text-zinc-500` |
| ボーダー | `border-gray-100` | `border-zinc-800` |

### 1.2 カテゴリーカラーの調整

ダークモードでは、ライトモード用の背景色（`bg-{color}-50`）が明るすぎるため、不透明度を調整した暗い背景と、視認性の高いテキスト色を使用する。

| カテゴリー | ライトBG | ダークBG | ダークテキスト |
|-----------|---------|---------|-------------|
| 授乳 (Feeding) | `bg-rose-50` | `bg-rose-950/30` | `text-rose-400` |
| 睡眠 (Sleep) | `bg-indigo-50` | `bg-indigo-950/30` | `text-indigo-400` |
| おむつ (Diaper) | `bg-amber-50` | `bg-amber-950/30` | `text-amber-400` |
| 成長 (Growth) | `bg-emerald-50` | `bg-emerald-950/30` | `text-emerald-400` |
| 陣痛 (Contraction) | `bg-red-50` | `bg-red-950/30` | `text-red-400` |

## 2. 実装方針

### 2.1 ライブラリ・機能

- **`next-themes`**: テーマ（Light / Dark / System）の状態管理と切り替え。
- **Tailwind CSS v4**: `dark:` 修飾子によるスタイリング。

### 2.2 コンポーネント構成

- `ThemeProvider`: アプリ全体をラップし、テーマ情報をコンテキストで提供。
- `ThemeToggle`: 以下の場所に配置する切り替えUI。
    - **グローバルヘッダー**: 全ページから即座に切り替え可能にするため、右側の設定アイコンの隣に配置。
    - **設定ページ**: 一般セクションの項目として配置。

## 3. 動作確認項目 (Verification)

### 3.1 機能確認

- [ ] テーマを「ダーク」に切り替えた際、即座にアプリ全体のUIが反映されるか
- [ ] システム設定（OS）のダークモード切り替えに追従するか（「システム設定に同期」選択時）
- [ ] ページをリロードしても、選択したテーマが保持されているか
- [ ] ログイン/ログアウト前後でテーマ設定が維持されるか

### 3.2 UI/デザイン確認

- [ ] ダークモード時、主要テキストと背景のコントラストが確保されているか（視認性の確認）
- [ ] 各カテゴリーカラー（rose, indigo等）がダークモードの背景色の上でも適切に見えるか
- [ ] カードやヘッダーの境界線が埋もれず、構造が把握できるか
- [ ] ページ遷移時に一瞬ライトモードが表示される（FOUC）現象が発生しないか

### 3.3 コンポーネント別確認

- [ ] ダッシュボード（各ウィジェット、プロフィールカード）
- [ ] 記録詳細ページ（授乳、睡眠、おむつ、成長、陣痛）
- [ ] フォーム要素（Input, Select, Button, タイムピッカー）
- [ ] 統計グラフ (Recharts) がダークモードでも見やすいか
- [ ] 設定画面
