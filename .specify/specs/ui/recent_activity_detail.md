# 仕様書: 最近の記録の表示改善と編集機能

## 1. 目的

ダッシュボードの「最近の記録（RecentActivityFeed）」において、メモが省略されて全文が読めない課題を解決し、さらにその場で記録の修正や削除を行えるようにすることで、ユーザーの利便性を向上させる。

## 2. ユーザーストーリー

- ユーザーは、ダッシュボードの「最近の記録」に表示されているメモの全文を、画面遷移なしで確認したい。
- ユーザーは、間違えて登録した記録やメモの内容を、ダッシュボードから直接編集・修正したい。
- ユーザーは、不要になった記録をその場で削除したい。

## 3. 機能要件

### 3.1. フロントエンド表示（RecentActivityFeed）

- **表示の改善**:
    - メモの表示を `truncate`（1行省略）から `line-clamp-2`（最大2行表示）に変更し、一目で内容を把握しやすくする。
- **インタラクション**:
    - 各記録項目をクリック（タップ）可能にする。
    - クリック時に詳細表示・編集用のダイアログを表示する。

### 3.2. 記録詳細・編集ダイアログ（RecordDetailDialog）

- **表示項目**:
    - 記録のタイプ（授乳、睡眠、おむつ、成長、メモ、陣痛）のラベル。
    - 記録された日時（yyyy/MM/dd HH:mm 形式）。※現状は表示のみ。
    - メモ内容（Textarea で表示）。
- **編集機能**:
    - メモ内容を編集し、保存できる。
    - 記録タイプに応じた適切なAPIエンドポイントへリクエストを送信する。
- **削除機能**:
    - 「削除」ボタンを配置し、確認後に記録を削除できる。

### 3.3. メモ一覧ページ（NotePage）

- **一覧表示**:
    - 全てのメモ記録を時系列降順で表示する。
    - 各メモの編集・削除が可能。
- **新規登録**:
    - ページ上部にメモ投稿フォームを配置。
- **ナビゲーション**:
    - サイドメニューおよびダッシュボードのウィジェットからアクセス可能。

### 3.4. バックエンド（API）

- **更新エンドポイントの活用**:
    - 授乳 (`PATCH /api/feedings/{id}`) ※新規追加済み
    - おむつ (`PATCH /api/diapers/{id}`)
    - 睡眠 (`PATCH /api/sleeps/{id}`)
    - 成長 (`PATCH /api/growths/{id}`)
    - メモ (`PATCH /api/notes/{id}`) ※フィールド名は `content`
    - 陣痛 (`PATCH /api/contractions/{id}`)

## 4. 非機能要件

- ダークモードに対応したUIデザイン。
- スマートフォンでの操作を考慮したタッチフレンドリーな設計。

## 5. 画面設計（ダイアログ）

- ヘッダー: 「[タイプ名]の記録」
- ボディ:
    - 日時表示（読み取り専用）
    - メモ入力欄（複数行）
- フッター:
    - 削除ボタン（左側、赤色テキスト）
    - キャンセルボタン
    - 保存ボタン（プライマリカラー）
