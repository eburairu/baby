# ランディングページ (Landing Page) 仕様書

## 概要
Botoro のトップページ（未認証時）として機能するランディングページ。
アプリのコンセプト（家族での共同育児記録）を伝え、新規登録（家族作成）および既存家族への参加へ誘導することを目的とする。

## ターゲットユーザー
- これから育児記録を始めようとしている親
- 家族（パートナー、祖父母）と記録を共有したいユーザー
- 紙の記録や既存アプリの複雑な共有機能に不満を感じているユーザー

## 構成セクション

### 0. ヘッダー (Header)
- **ロゴ**: Botoro (左側)
- **ナビゲーション**: 
    - 特徴
    - 機能
- **アクション**:
    - [ログイン] -> `/login` (右側)

### 1. ヒーローセクション (Hero)
- **背景**: `bg-slate-50`
- **キャッチコピー**: 「家族の絆を、育児記録で深める。Botoro」
- **サブコピー**: 授乳、睡眠、おむつの記録をリアルタイムで共有。AIによる振り返りで、赤ちゃんの成長をもっと身近に。
- **CTAボタン**:
    - [新しく家族を登録する] -> `/register` ( `bg-indigo-600` )
    - [招待コードで参加する] -> `/register?join=true` ( `variant="outline"` )
- **ビジュアル**: アプリのメイン画面（ダッシュボード）のモックアップ画像
    - 画像パス: `/screenshots/dashboard.png` (スマホ用モックアップの枠に配置)
    - 未設置時のフォールバックとして `bg-slate-200` のプレースホルダーを表示

### 2. 特徴セクション (Key Features)
3つの柱で紹介。各カードは `rounded-2xl shadow-sm`。
- **リアルタイム共有**: 「パパが記録、ママが確認」。職場からでも赤ちゃんの様子がわかります。
- **AI サマリー**: 毎日の記録をAIが分析。授乳リズムや睡眠パターンを要約してアドバイス。
- **シンプル操作**: 授乳タイマーやおむつ記録など、片手で操作できるUI。
- **視認性**: テキストカラーは `text-slate-600` 以上（背景 `bg-white` または `bg-slate-50`）を維持し、白背景に白文字などの視認不可な状態を避ける。

### 3. 機能一覧 (Detailed Features)
アイコン付きのグリッドレイアウトで紹介。
- 🤱 授乳・ミルク記録（左右タイマー対応 / `rose` カラー）
- 💤 睡眠記録（タイマー・統計 / `indigo` カラー）
- 💩 おむつ・健康状態（ `amber` カラー）
- 📈 成長グラフ（身長・体重 / `emerald` カラー）
- 💬 応援コメント機能
- 🔔 プッシュ通知

### 4. セキュリティ・信頼性 (Security & Trust)
- **招待制**: 家族だけのプライベートな空間。
- **セキュアなデータ管理**: 認証情報と記録を安全に保護。

## UI/UX 指針
- **デザイン**: `ui_design_system.md` に準拠。
    - ページ背景: `bg-slate-50`
    - カード: `rounded-2xl shadow-sm border-0`
    - 送信ボタン: `bg-indigo-600 hover:bg-indigo-700 text-white`
- **視認性確保**:
    - 背景が `bg-indigo-600` のセクション（フッター CTA）では、テキストは必ず `text-white` または `text-indigo-100` を使用。
    - 背景が `bg-white` または `bg-slate-50` のセクションでは、テキストは `text-slate-600` または `text-slate-900` を使用。
- **アクセシビリティ**: 文字サイズ、コントラスト、ボタンの押しやすさに配慮。
- **レスポンシブ**: モバイルファースト。外出先（片手操作）を強く意識した設計。

## 技術仕様

### 1. ルーティングの変更
現在 `/` に配置されているダッシュボードを `/dashboard` へ移動し、LP を `/` に配置する。

| パス | 内容 | アクセス制御 |
|---|---|---|
| `/` | ランディングページ | 誰でもアクセス可能。認証済みの場合は `/dashboard` へ自動リダイレクト。 |
| `/dashboard` | ダッシュボード | 認証必須。未認証の場合は `/login`（または `/`）へリダイレクト。 |
| `/login` | ログイン画面 | 未認証時のみ。 |
| `/register` | 登録画面 | `?join=true` パラメータで「家族に参加」タブを初期選択。 |
| `/privacy` | プライバシーポリシー | 誰でも閲覧可能。 |
| `/terms` | 利用規約 | 誰でも閲覧可能。 |

### 2. 認証リダイレクトの実装
- **未認証ユーザー**:
    - `/` (LP) を閲覧可能。
    - `/dashboard` 等の保護されたルートへアクセスした場合は `DashboardLayout` により `/login` へリダイレクト。
- **認証済みユーザー**:
    - `/` (LP) にアクセスした場合、自動的に `/dashboard` へリダイレクト。

### 3. コンポーネント
- shadcn/ui (Hero, Card, Button, Accordion)
- Framer Motion を使用したスムーズなスクロールとフェードイン。
