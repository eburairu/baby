# ランディングページ (Landing Page) 仕様書

## 概要
Baby App のトップページ（未認証時）として機能するランディングページ。
アプリのコンセプト（家族での共同育児記録）を伝え、新規登録（家族作成）および既存家族への参加へ誘導することを目的とする。

## ターゲットユーザー
- これから育児記録を始めようとしている親
- 家族（パートナー、祖父母）と記録を共有したいユーザー
- 紙の記録や既存アプリの複雑な共有機能に不満を感じているユーザー

## 構成セクション

### 0. ヘッダー (Header)
- **ロゴ**: Baby App (左側)
- **ナビゲーション**: 
    - 特徴
    - 機能
- **アクション**:
    - [ログイン] -> `/login` (右側)
    - ※ 認証済みの場合はダッシュボード等への遷移ボタンを適宜表示検討（現在はログインのみ）

### 1. ヒーローセクション (Hero)
- **背景**: `bg-slate-50`
- **キャッチコピー**: 「家族の絆を、育児記録で深める。Baby App」
- **サブコピー**: 授乳、睡眠、おむつの記録をリアルタイムで共有。AIによる振り返りで、赤ちゃんの成長をもっと身近に。
- **CTAボタン**:
    - [新しく家族を登録する] -> `/register` ( `bg-indigo-600` )
    - [招待コードで参加する] -> `/register?join=true` ( `variant="outline"` )
- **ビジュアル**: アプリのメイン画面（ダッシュボード）のモックアップ画像

### 2. 特徴セクション (Key Features)
3つの柱で紹介。各カードは `rounded-2xl shadow-sm`。
- **リアルタイム共有**: 「パパが記録、ママが確認」。職場からでも赤ちゃんの様子がわかります。
- **AI サマリー**: 毎日の記録をAIが分析。授乳リズムや睡眠パターンを要約してアドバイス。
- **シンプル操作**: 授乳タイマーやおむつ記録など、片手で操作できるUI。

アイコン付きのグリッドレイアウトで紹介。

- 💬 応援コメント機能
- 🔔 プッシュ通知

### 4. セキュリティ・信頼性 (Security & Trust)
- **招待制**: 家族だけのプライベートな空間。
- **セキュアなデータ管理**: 認証情報と記録を安全に保護。

- **デザイン**: `ui_design_system.md` に準拠。

## 技術仕様

### 1. ルーティング
現在 `/` に配置されているダッシュボードを `/dashboard` へ移動し、LP を `/` および `/about` に配置する。

| パス | 内容 | アクセス制御 |
|---|---|---|
| `/` | ランディングページ | 誰でもアクセス可能。認証済みの場合は `/dashboard` へ自動リダイレクト。 |
| `/about` | 紹介ページ（LPと同一） | 誰でもアクセス可能。**認証済みでもリダイレクトせず**、アプリの紹介として閲覧可能。 |
| `/dashboard` | ダッシュボード | 認証必須。未認証の場合は `/login` へリダイレクト。 |
| `/login` | ログイン画面 | 未認証時のみ。 |
| `/register` | 登録画面 | `?join=true` パラメータで「家族に参加」タブを初期選択。 |

### 2. 認証リダイレクトの実装
- **未認証ユーザー**:
    - `/` および `/about` を閲覧可能。
    - `/dashboard` 等の保護されたルートへアクセスした場合は `DashboardLayout` により `/login` へリダイレクト。
- **認証済みユーザー**:
    - `/` にアクセスした場合、自動的に `/dashboard` へリダイレクト。
    - `/about` にアクセスした場合はリダイレクトせず、そのまま表示する。

### 3. 設定画面からの導線
- 設定画面（`/settings`）の「アプリ情報」セクションに、「Baby App について」という項目を追加する。
- クリックすると `/about` ページへ遷移する。

### 4. コンポーネント
- shadcn/ui (Hero, Card, Button, Accordion)
- Framer Motion を使用したスムーズなスクロールとフェードイン。
