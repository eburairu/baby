# WHO成長曲線表示機能 仕様書 (WHO Growth Standards Specification)

## 概要

WHO（世界保健機関）が公開している成長基準（Growth Standards）に基づいた成長曲線を、既存の成長記録グラフに重ねて表示する機能。
これにより、保護者は子供の発育が標準的な範囲内にあるか、どのような推移をたどっているかを直感的に把握できる。

## ユーザーストーリー

- 親として、子供の身長・体重が同月齢の子供と比べてどのくらいか知りたい。
- 成長曲線（パーセンタイル）を表示して、極端な外れ値がないか確認したい。
- 男の子用・女の子用の適切な基準で比較したい。

## 要件

### R1. 赤ちゃんの性別管理

WHOの成長基準は男女別で定義されているため、赤ちゃん情報に性別を追加する。

- **データモデル変更**: `babies` テーブルに `gender` カラムを追加。
    - 値: `male` (男の子), `female` (女の子), `other` (その他)
- **UI変更**:
    - 赤ちゃん登録・編集画面に性別選択ラジオボタンを追加 (必須項目)。

### R2. WHO成長基準データの保持

WHOが公開している以下のデータをアプリケーション内で保持する (JSON/TS形式)。
データ量削減のため、必要なポイント（例：0ヶ月〜5歳までの1ヶ月ごとのP3, P15, P50, P85, P97）に絞る。

- **対象データ**:
    - Length/height-for-age (年齢別身長)
    - Weight-for-age (年齢別体重)
    - Head circumference-for-age (年齢別頭囲) 
- **保持形式**: `frontend/constants/who_standards_data.ts`
      ```typescript
      export const WHO_STANDARDS = {
        male: {
          height: [{ month: 0, p3: 46.3, p50: 49.9, p97: 53.4 }, ...],
          weight: [...],
          head: [...]
        },
        female: { ... }
      };
      ```

### R3. グラフへの重ね合わせ表示

既存の `Recharts` グラフに、WHO基準の曲線を背景として描画する。

- **X軸の扱い**:
    - 現行: 日付 (Date)
    - 変更方針:
        - X軸は「日付」のまま維持。
        - 赤ちゃんの `birthday` と `gender` を元に、WHOデータの `month` (月齢) を「その月齢になる日付」に変換してプロットする。
        - 例: 誕生日が 2024-01-01 の場合、1ヶ月時点のデータは 2024-02-01 のX座標にプロット。
- **表示内容**:
    - **P50 (中央値)**: 実線または太線で表示（基準線）。
    - **帯 (Area)**:
        - P3 〜 P97 の範囲を薄い色で塗りつぶし (正常範囲の目安)。
        - 重ね順: 背景(WHO Area) -> WHO P50 Line -> User Data (Dots/Line).
- **インタラクション**:
    - ツールチップに「WHO平均: XX cm」などを表示できると望ましい。
    - チェックボックスで「成長曲線を表示/非表示」を切り替え可能にする。

## テスト・検証項目

### 1. データ不整合テスト
- [ ] 性別のない赤ちゃんが存在する場合の挙動（デフォルト値を適用するか、エラーにならず非表示になるか）。
- [ ] WHOデータが存在しない月齢（5歳以上など）における描画確認。

### 2. 境界値テスト
- [ ] 生まれたて（0ヶ月0日）のプロット位置が正しいか。
- [ ] うるう年を含む期間での月齢計算が正しいか。

### 3. 表示テスト
- [ ] グラフのY軸スケールが、ユーザーの極端な入力値（例: 身長10cmや200cm）とWHO基準値の両方を正しく収めるように自動調整されるか。
- [ ] 性別を切り替えた際、即座にグラフの基準線が再描画され、値が変化するか（男児の方が女児よりやや大きい傾向など）。
