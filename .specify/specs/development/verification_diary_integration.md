# 動作確認項目: 育児日誌のダッシュボード統合と共通化

## 1. ナビゲーションの確認

### デスクトップ
- [ ] サイドバーまたはヘッダーメニューに「育児日誌」項目が表示されている。
- [ ] クリックして `/diary` ページに遷移できる。

### モバイル
- [ ] ボトムナビゲーションに「日誌」アイコンが表示されている。
- [ ] ボトムナビゲーションの項目が「ホーム、授乳、睡眠、おむつ、日誌」の順序で並んでいる。
- [ ] 「設定」がボトムナビゲーションから消え、サイドメニュー（Sheet）内にのみ存在することを確認。

## 2. ダッシュボードウィジェットの確認

### 育児日誌ウィジェット (DiaryWidget)
- [ ] 授乳や睡眠と同じサイズのカードとしてグリッド内に表示されている。
- [ ] 最新の育児日誌のサマリー文が表示されている。
- [ ] 日誌が未作成の場合、「日誌がありません」等の適切なプレースホルダーが表示される。
- [ ] 右上の矢印ボタンから `/diary` ページへ遷移できる。

### メモウィジェット (NoteWidget)
- [ ] 以前のフル幅表示から、他のウィジェットと同じ 2カラムサイズに変更されている。
- [ ] 最新のメモ内容が表示されている。
- [ ] 右上の矢印ボタンから `/note` ページへ遷移できる。

### レイアウト共通化
- [ ] ウィジェット間の余白、角丸、フォントサイズ、アイコンの色（amber-500）が統一されている。
- [ ] ホバー時の浮き上がりアニメーションが全ウィジェットで動作する。

## 3. クイックアクションの確認

- [ ] クイックアクションバーの右端に 📝（メモ）ボタンが追加されている。
- [ ] ボタンをクリックすると、メモ入力用のアクション（ダイアログ表示または即時入力モード）が起動する。
- [ ] メモを投稿した後、ダッシュボードの「メモ」ウィジェットが即座に更新される。

## 4. 異常系・エッジケースの確認

- [ ] ネットワークエラー時に、他のウィジェットと同様のエラー表示（閲覧制限等）が出る。
- [ ] データ読み込み中にスケルトンまたはローディングスピナーが表示される。
- [ ] 赤ちゃんを切り替えた際、日誌とメモの内容も正しく切り替わる。
