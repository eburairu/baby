# ダッシュボードUIのハニカム構造化

## 概要
ダッシュボードをハニカム構造化し、見栄えを良くして独自性を高める。
ハニカム構造はすでにクイックアクションで使用されている（`frontend/components/ui/hexagon.tsx` 等）。

## 目標
1. ダッシュボード全体のレイアウトをハニカム構造（六角形のタイル）に刷新する。
2. 既存のウィジェットをハニカムタイル内に収める、または再配置する。
3. 視覚的な美しさと使いやすさを両立させる。
4. すでに実装済みのハニカム構造コンポーネントを再利用する。
