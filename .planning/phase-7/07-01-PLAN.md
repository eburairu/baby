# フェーズ 7 計画: 閾値設定UIの実装

## 概要
設定画面の赤ちゃん編集フォームに、授乳とおむつのカスタム閾値（警告タイミング）を設定できる入力フィールドを追加し、バックエンドへ保存できるようにします。

## 依存関係
- **フェーズ 5**: バックエンドAPI（`PATCH /babies/{id}`）が `feeding_threshold_minutes` と `diaper_threshold_minutes` を受け取れるようになっていること
- **フェーズ 6**: ダッシュボードのインジケーターがこれらの値を参照するようになっていること

## 変更ファイル
- `frontend/types/baby.ts` (型定義)
- `frontend/components/settings/BabyForm.tsx` (フォームUI)
- `frontend/components/settings/BabyEditDialog.tsx` (API連携)
- `frontend/components/settings/AddBabyDialog.tsx` (新規追加時)

## 実装タスク

### 1. 型定義の更新
`frontend/types/baby.ts` に以下のフィールドを追加します。
- `feeding_threshold_minutes?: number | null`
- `diaper_threshold_minutes?: number | null`

### 2. フォームUIの拡張 (`BabyForm.tsx`)
- `babySchema` (Zod) に `feeding_threshold_minutes`, `diaper_threshold_minutes` を追加。
  - `z.coerce.number().min(0).optional().nullable()`
- JSX内に数値入力フィールドを追加。
  - `Label`: 「授乳の警告閾値（分）」「おむつの警告閾値（分）」
  - `Input`: `type="number"`, `placeholder="空欄で自動設定"`
  - `FormDescription`: 「前回記録からの経過時間がこの分を超えると警告（赤色）が表示されます。」

### 3. API連携の修正 (`BabyEditDialog.tsx` / `AddBabyDialog.tsx`)
- `api.patch` / `api.post` のペイロードに `feeding_threshold_minutes` と `diaper_threshold_minutes` を含めるように修正します。

## 検証タスク

### 自動テスト (TDD)
- `frontend/__tests__/components/settings/BabyForm.test.tsx` (新規作成)
  - 閾値フィールドが表示されていること。
  - 数値を入力して送信した際、期待通りのデータ構造が `onSubmit` に渡されること。
  - 空欄で送信した際、`null` または `undefined` が渡されること。

### 手動検証
1. 赤ちゃん設定画面 (`/settings/babies`) を開く。
2. 赤ちゃんの「編集」ボタンをクリック。
3. 授乳閾値に `120`、おむつ閾値に `180` と入力して「保存」をクリック。
4. 再度「編集」を開き、入力した値が保持されていることを確認。
5. 値を消去して保存し、自動設定（推奨値）に戻る挙動をバックエンドAPIのレスポンス（`null`）で確認。
