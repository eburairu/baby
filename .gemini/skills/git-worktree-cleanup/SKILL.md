# Git Worktree Cleanup Skill

## Instructions

このスキルは、プロジェクト内の Git ワークツリーとマージ済みブランチをクリーンアップするために使用されます。ユーザーから「ワークツリーをクリーンアップして」という指示があった際に呼び出されます。

実行する際は、以下の手順に従ってください：

1. `sh scripts/cleanup_worktrees.sh` を実行します。
2. 実行結果（どのワークツリーやブランチが削除されたか）をユーザーに報告します。

## Available Resources

- `scripts/cleanup_worktrees.sh`: 実際のクリーンアップロジック。
